# Maria Mospanova — Photography

Сайт-портфоліо фотографа: Sport / Events / Fashion.
Статичний сайт (HTML + CSS + vanilla JS), без фреймворків і без збірки, тож його можна просто завантажити на [tiiny.host](https://tiiny.host).

```
index.html            вся розмітка сторінки
assets/css/style.css  дизайн, анімації, мобільна версія
assets/js/main.js     поведінка: поява фото, фільтр, стрічка, лайтбокс
assets/img/           сюди кладуться фото Марії
```

## 2. Що взяли і чим відрізняємось

**Взяли з референсу:** хедер-індекс на 4 колонки, навігацію в квадратних дужках, двотонові підписи (чорний + сірий), фільтр з кількістю робіт, сітку з порожніми клітинками, рядки «label → value».

**Свої деталі, щоб сайти не були схожі:**

1. **Теплий off-white** `#F1EEE8` замість чистого білого.
2. **Serif-курсив** (Instrument Serif) для акцентних слів: *together*, *sports, events and fashion*.
3. **Один акцентний колір**: глиняно-червоний `#C8432B`, лише на дужках активного пункту меню.
4. **Перший екран — колаж** із 7 фото, які з'являються по черзі (stagger + clip-reveal), а не одне фото.
5. **Живий хедер**: при скролі або наведенні на фото показує назву роботи, категорію і номер.
6. **Асиметрична editorial-сітка**: фото різних розмірів, full-width кадри, вертикальні зсуви.
7. **Блок Approach**: великі слова MOVEMENT / ENERGY / PEOPLE / MOMENTS дрейфують при скролі, а при наведенні з'являється фото.
8. **Горизонтальна стрічка Selected Work**: на десктопі звичайний вертикальний скрол рухає її вбік, на телефоні вона гортається свайпом.
9. **Живий час Берліна** в контактах і курсор-мітка `VIEW` над фото.

## 3. Структура сторінки (логіка з ТЗ)

```
ФОТО (колаж)  →  WORK (сітка + фільтр)  →  ABOUT  →  APPROACH  →  SELECTED (стрічка)  →  CONTACT  →  FOOTER
```

Анімації делікатні: fade, легкий рух, без zoom і 3D. Якщо в системі ввімкнено «зменшити рух», усе показується одразу, без анімацій.

## 4. Як замінити фото

Зараз на сайті вже стоять фото Марії (27 кадрів з Google Drive, стиснені до ~10 MB, EXIF/GPS видалено). Кожне місце на сайті має **фіксовану назву файлу**. Достатньо покласти своє фото з потрібною назвою в папку `assets/img/`, і сайт підхопить його сам, код правити не треба. Поки файлу немає, на його місці показується тимчасове фото.

**Кроки:**
1. Підготуйте фото: JPG, довга сторона ~2000px, вага до 300–500 KB (наприклад, через [squoosh.app](https://squoosh.app)).
2. Перейменуйте їх за таблицею нижче (назви мають збігатися точно: маленькі літери, `.jpg`).
3. Покладіть у `assets/img/`.
4. Щоб побачити, яке фото куди йде, відкрийте сайт з `?map` у кінці адреси (наприклад `index.html?map`): на кожному фото з'явиться назва його файлу.

**Підписи і категорії** в Work (назва роботи, Sport/Events/Fashion) змінюються в `index.html`, у блоці потрібної `<figure class="tile">`:
- `<figcaption class="cap"><span>Назва</span><span>Категорія</span></figcaption>`: підпис;
- `data-cat`: `sport`, `events` або `fashion` (по ньому працює фільтр);
- кількість робіт у фільтрі (`Sport (6)`) оновіть, якщо змінюєте категорії.

## 6. Публікація на tiiny.host

1. Запакуйте **вміст** папки (а не саму папку) в zip, щоб `index.html` лежав у корені архіву.
   Готовий архів: `maria-mospanova-site.zip`.
2. Зайдіть на tiiny.host → введіть назву (наприклад `maria-mospanova`) → завантажте zip → **Publish**.
3. Сайт буде доступний за адресою `maria-mospanova.tiiny.site`. Власний домен підключається на платному тарифі.
4. Ліміт розміру залежить від тарифу, тому фото обов'язково стискайте (див. п. 4).

Локальний перегляд: просто відкрийте `index.html` у браузері.
